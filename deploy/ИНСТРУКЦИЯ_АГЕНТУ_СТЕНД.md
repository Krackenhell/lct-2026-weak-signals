# Инструкция агенту: обновить демо-стенд до финальной версии

**Цель:** на сервере стенда запустить ветку `main` репозитория `Krackenhell/lct-2026-weak-signals` (коммит `158f177` или новее)
с новыми ключами и проверить, что всё работает. Время работы — около 30 минут.

**Сервер:** Windows, IP `77.239.111.137`, Нидерланды. Стенд запускается без Docker: `run_windows.bat` поднимает сторож
`deploy\supervisor.py`, а тот запускает `uvicorn` и сам подтягивает обновления ветки `main`. Сайт и API отдаёт один процесс
(FastAPI раздаёт собранный фронтенд из `frontend\dist`), Node.js на сервере **не нужен**.

## Правила

- Код не менять, ничего не коммитить и не пушить. Только `git pull`, настройка `.env`, запуск и проверка.
- Значения ключей не выводить в чат, логи и скриншоты. Файл `.env` в git не попадает — так и должно остаться.
- Перед заменой `.env` сделать резервную копию: `copy .env .env.backup-20-10`.
- Если что-то пошло не так — откат (раздел «Откат») и сообщить, на каком шаге ошибка и её точный текст.

## Шаг 1. Найти проект и остановить старый сервер

```powershell
# Папка проекта — та, где лежит run_windows.bat. Если неизвестна:
Get-ChildItem C:\,D:\ -Recurse -Filter run_windows.bat -ErrorAction SilentlyContinue -Depth 4 | Select-Object FullName
cd <папка проекта>
# Остановить работающий стенд: закрыть окно run_windows.bat или
Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -match "supervisor.py|uvicorn app.main" } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

Проверка: `curl http://127.0.0.1:8080/api/health` больше не отвечает.

## Шаг 2. Получить финальный код

```powershell
git fetch origin
git checkout main
git pull --ff-only origin main
git log --oneline -1          # ожидается 158f177 «Слияние final-improvements…» или новее
```

Если `git pull` ругается на локальные изменения: `git stash`, затем снова `git pull --ff-only origin main`.

## Шаг 3. Ключи в `.env`

Иван передаёт файл `.env` со своего компьютера (`D:\МСК ХАК\lct-2026-weak-signals\.env`) — через RDP (копирование файла)
или вставкой содержимого. Положить его в корень проекта рядом с `run_windows.bat` (предварительно сделав резервную копию старого).

Обязательно проверить, что в `.env` есть строки (значения — из файла Ивана):

```
DECISION_PROVIDER=jev
TYPESAFE_API_KEY=…
```

И дописать в конец (если этих строк нет):

```

```

`DATABASE_URL` не задавать: стенд хранит данные в `backend\data\local.db` (история прошлых запросов экспертов сохраняется).

## Шаг 4. Запуск

```powershell
$env:PORT = "8080"
.\run_windows.bat
```

Сторож сам установит зависимости из `backend\requirements.txt` (первый раз — 2–5 минут; появились `certifi`, `pypdf`,
`httpx[socks]`) и запустит сервер. Окно не закрывать. Для автозапуска после перезагрузки — «Планировщик заданий» →
«При запуске компьютера» → `cmd /c "set PORT=8080 && <папка проекта>\run_windows.bat"`.

## Шаг 5. Проверка (все пункты обязательны)

```powershell
curl http://127.0.0.1:8080/api/health
# ожидается {"status":"ok","commit":"158f177"} (или новее)

curl http://127.0.0.1:8080/api/model
# в ответе: "trained": true, 18 признаков в "weights", в "metrics" → "cv5" → "f1": 0.894

cd backend
.venv\Scripts\python -m scripts.check_sources "solid state battery" "твердотельный аккумулятор"
# ожидается OK у большинства из 23 источников. Допустимо ERR у GDELT (лимит частоты), КиберЛенинки и Роспатента
# (российские сайты из Нидерландов отвечают нестабильно). Если ERR у OpenAlex, Jev/GigaChat не проверяются этим скриптом —
# см. следующий пункт.

.venv\Scripts\python -m app.ml.renormalize_names
# применяет исправленный глоссарий русских названий к уже сохранённым результатам; печатает {'names': N, 'texts': M}
cd ..
```

В браузере на самом сервере открыть `http://77.239.111.137:8080/`:
1. Главная: светлый дизайн, 3D-радар справа от строки поиска, три 3D-иллюстрации ниже.
2. Ввести «твердотельные аккумуляторы» → «Найти сигналы». Во время поиска — радар с точками-находками и лентой справа.
   Через 4–6 минут — список сигналов (обычно 6–15), у каждого «Оценка», квадраты «проверки», «балл места».
3. Открыть первый сигнал → досье: описание, «Почему рано», справка, «Путь от науки до рынка», источники с типом, языком и доверием.
4. Нигде не должно быть «100%» (максимум — «> 95%»).

Если поиск закончился с ошибкой — прислать текст ошибки со страницы и последние 50 строк `deploy\supervisor.log`.

## Шаг 6. Прогрев тем-примеров (после 03:00 МСК)

Квота OpenAlex обнуляется около 03:00 МСК; 20.10 она почти израсходована замером. После сброса:

```powershell
cd backend
.venv\Scripts\python -m app.precompute --queries "технология многослойного графена;микрофлюидные чипы;твердотельные аккумуляторы;постквантовая криптография;перспективные решения в финтехе;кибербезопасность ИИ"
```

Каждая тема — 4–6 минут; потом клик по примеру на главной открывает готовый ответ за секунду.

## Домен (по желанию Ивана)

Если куплен домен: запись A у регистратора → `77.239.111.137`; в брандмауэре открыть входящие TCP 80 и 443; скачать `caddy.exe`
(caddyserver.com/download, Windows amd64) в папку проекта; запускать стенд с `$env:PORT="8081"` и рядом
`$env:DOMAIN="<домен>"; .\caddy.exe run --config deploy\Caddyfile`. Caddy сам получит HTTPS-сертификат и сохранит старый
адрес `http://77.239.111.137:8080`. Подробно — `deploy/ВЫКАТКА_20-10.md`, раздел 3.
