# Выкатка финальной версии на стенд — чек-лист на 20.10

Стенд: Windows-сервер в Нидерландах, `77.239.111.137`. Запуск без Docker через `run_windows.bat`; сторож `deploy/supervisor.py`
сам подтягивает ветку `DEPLOY_BRANCH` (по умолчанию `main`) и перезапускает сервер.

## 1. Код (делает разработчик, 2 минуты)

- `final-improvements` сливается в `main` (после финального замера `docs/ЗАМЕР_ВЫДАЧИ.md`).
- Проверка после выкатки: `http://77.239.111.137:8080/api/health` → в поле `commit` новый коммит; `/api/model` → 18 признаков, F1 0,894.

## 2. Сервер стенда (RDP, 10–15 минут)

1. Остановить старый сервер (закрыть окно `run_windows.bat`).
2. `git pull` в папке проекта (или дождаться сторожа).
3. Дописать в `.env` новые ключи (значения — у Ивана, в чат и в git не класть):
   ```
   OPENALEX_API_KEY=…             # новый
   OPENALEX_API_KEY_BACKUP=…      # прежний — запасной
   BRAVE_API_KEY=…
   NCBI_API_KEY=…  NASA_ADS_TOKEN=…  STACKEXCHANGE_KEY=…  LENS_API_TOKEN=…
   EPO_OPS_KEY=…  EPO_OPS_SECRET=…  ROSPATENT_API_KEY=…
   SEC_USER_AGENT=AgentsOfMoscow <почта не на mail.ru>
   USE_WATCHLIST=false
   PRECOMPUTE_EVERY_HOURS=0
   ```
4. Запуск: `set PORT=8081` и `run_windows.bat` (порт 8081, наружу его отдаёт Caddy — см. п. 3).
   Без домена можно по-старому: `set PORT=8080` и `run_windows.bat`.
5. Проверка источников со стенда: `cd backend && .venv\Scripts\python -m scripts.check_sources "solid state battery" "твердотельный аккумулятор"`.
6. Применить глоссарий к старым прогонам: `.venv\Scripts\python -m app.ml.renormalize_names`.
7. Прогреть темы-примеры (11 тем, около часа в фоне): `curl -X POST http://127.0.0.1:8081/api/precompute`.

## 3. Домен и HTTPS (15 минут)

1. Купить домен (`.ru`, около 200 ₽/год) и в DNS у регистратора сделать запись **A → 77.239.111.137** (и `www` → тот же адрес).
2. В брандмауэре Windows открыть входящие **TCP 80 и 443** (порт 8080 уже открыт).
3. Скачать Caddy для Windows (один файл `caddy.exe`, caddyserver.com/download) в папку проекта.
4. Запуск: `set DOMAIN=ваш-домен.ru` и `caddy run --config deploy\Caddyfile`.
   Caddy сам получит сертификат Let's Encrypt (нужно, чтобы DNS уже указывал на сервер), отдаст сайт по `https://ваш-домен.ru`
   и сохранит старый адрес `http://77.239.111.137:8080`.
5. Автозапуск: `caddy.exe` и `run_windows.bat` — в «Планировщик заданий» → «При запуске компьютера».

## 4. Перед питчем 23.10

- За 2 часа: `/api/health`, открыть 2–3 готовые темы, одну новую тему; ничего не пушить.
- Если ЕИС на стенде отвечает пусто — прокси через ПК Ивана (Tailscale) или российский VPS (`deploy/ru-proxy-setup.sh`), см. `DEPLOY.md`.
