### Как запустить у себя
См. README → «Локальная разработка без Docker». Ключи — в `.env` (образец `.env.example`).

### Ждём ключи
- `TYPESAFE_API_KEY` (Jev) — затем `python -m app.ml.train --reask`, чтобы переобучить классификатор на ответах Jev.
- `GIGACHAT_AUTH_KEY` (бесплатный лимит для физлиц на developers.sber.ru) — русские досье и резюме.
- По желанию: `OPENALEX_API_KEY` (бесплатно на openalex.org), `GITHUB_TOKEN` (токен без прав) — выше лимиты, быстрее запрос.
