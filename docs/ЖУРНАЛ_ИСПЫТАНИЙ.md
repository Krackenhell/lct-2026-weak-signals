# Журнал испытаний

История проверок качества, скорости и устойчивости: какие модели и источники использовались, что получилось,
какие ошибки нашли и как исправили. Новые живые прогоны дописываются в конец автоматически
(`python -m app.ml.eval_live ... --label "что проверяем"`), полные результаты каждого прогона — в `backend/data/experiments/`.

Как читать «совпадения с датасетом»: сколько сигналов из таблицы организатора по этой области попало в наш топ-15
(строгое сравнение по словам названия). «С базой отслеживания» — система перепроверяет известные сигналы таблицы
вместе с новыми; «только обнаружение» — честный поиск с нуля по открытым источникам.
