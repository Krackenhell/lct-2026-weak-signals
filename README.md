# ЛЦТ 2026 — слабые технологические сигналы

Общий открытый репозиторий команды для задачи Газпромбанк.Тех на хакатоне «Лидеры цифровой трансформации — 2026».

**Состояние:** исследование задачи и рынка завершено; концепцию решения команда выбирает после обсуждения. Код появится здесь по мере разработки.

## Цель задачи

По свободному запросу о технологическом направлении находить ранние научно-технологические сигналы в открытых источниках. Для каждого результата показывать проверяемые источники, объяснение и пример применения; отделять ранние технологии от зрелых рынков и информационного шума.

## Как работаем вдвоём

Оба участника пишут код по очереди. Один ход — одна завершённая задача в отдельной ветке:

1. Перед началом хода обновить локальную копию и выбрать задачу из Issues.
2. Сделать изменение, проверить рабочий сценарий и открыть Pull Request.
3. В описании оставить: что сделано, как проверить, что осталось и что должен взять следующий участник.
4. Второй участник просматривает изменение и объединяет его с основной веткой. Затем начинает свой ход.

Не добавляем в открытый репозиторий ключи API, пароли, личные данные и исходные материалы организаторов без проверки права на публикацию.
